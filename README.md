# Python 学习记录

这里记录每天的学习总结、课程作业和额外练习。按实际学习进度走，不强行套六个月的固定路线。

## 每天在这里做什么

1. 在 [`daily/`](daily/) 记录今天学了什么、哪里没懂、明天接着做什么。
2. 把课程布置的题目放在 [`Assignments/`](Assignments/)。
3. 把自己额外写的代码放在 [`practice/`](practice/)。

代码文件尽量按课程日期或主题归类，运行过再提交。一个简单练习不需要额外拆出项目、知识点实验等目录。

## 当前进度

- 每日总结：查看  daily/
- 课程作业：查看 `Assignments/`
- 个人练习：查看 `practice/`
- 学习节奏：[roadmap.md](roadmap.md)

## 每天结束时

- 总结用自己的话写，没记录或没验证的内容就标出来，不补造。
- 作业和练习至少自己运行一次；遇到问题，把报错和修复记下来。
- 提交前看一眼 `git status` 和 `git diff`，确认只包含今天要交的内容。
