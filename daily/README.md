## 每日总结结构

新总结暂时按下面四个核心区写。已经完成的详细总结保留原样，不需要为了统一格式重写：

```markdown
# YYYY-MM-DD · DayXX：今天的主题

## 今天学了什么

## 我实际写了什么

- 作业：
- 练习：

## 遇到的问题

## 明天继续
```

作业链接到 `Assignments/day_XX_work/`，自主练习链接到 `practice/day_XX/`。自习日可以记录预习、补作业、复习、环境配置和额外实践。
