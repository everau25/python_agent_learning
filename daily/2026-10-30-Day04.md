# 2026-10-30 · Day04：判断语句和循环语句

## 今天学了什么

- **运算符**：算术（`+ - * / // % **`，`//` 取商、`%` 取余、`**` 幂）、赋值（`=`，以及 `a, b = b, a` 互换）、复合赋值（`+= -= *= /= //= %= **=`，先算术后赋值）、比较（`== != > < >= <=`，结果是布尔值）、逻辑（`and` 全真才真、`or` 有一真就真、`not` 取反，主要和 if 结合用）。
- **if 判断**：`if`、`if...else`、`if...elif...else`（从上往下，命中一个就不再往下比，如成绩分段 90 / 75 / 60）；**if 嵌套**的原则是先写外层、写完再写内层，如酒精含量先判是否 ≥20，再在里面判是否 ≥80 区分酒驾和醉驾。
- **循环的选择**：有条件地重复做一件事。次数固定（已知）用 for，如 1~100；次数未知（不确定）用 while，如猜数字直到猜对。
- **while 循环三步**：初始化计数器、写循环条件、循环体内更新计数器。案例：1~100 求和（5050）、1~100 偶数和（配合 `i % 2 == 0` 判断）。
- **break / continue**：break 是终止整个循环；continue 是跳过本次、进入下一次。吃苹果的例子：第 3 个吃饱了就 break，后面不吃了；第 3 个吃出虫子就 continue，吃第 4 个。**用 continue 时一定要先更新计数器，否则会死循环**；条件永久成立的 `while True` 本身就是死循环。
- **for 循环**：`for 临时变量 in 序列`，每次把序列里的一个元素依次交给临时变量，序列多长就循环多少次。`range(start, stop, step)`：start 默认 0，stop 不含在内，step 默认 1，如 `range(1, 101)` 是 1~100，`range(0, 101, 2)` 直接取偶数。
- **for...else**：else 里的代码只在循环**正常结束**后执行。遇到 break 退出，else 不执行；遇到 continue 只是跳过本次，循环仍会完整结束，else 照常执行。
- **综合案例**：猜数字（`random.randint(1, 100)`，while True + if 判断猜大 / 猜小 / 猜对，猜对 break）、for 循环登录（3 次机会，用户名错 / 密码错 / 成功三种情况，成功 break）。

## 遇到的问题

- 现象：for 循环里的**嵌套循环有点懵**，特别是九九乘法表：不知道外层和内层谁先谁后、内层为什么是 `range(1, i + 1)`、为什么一行打完要换行。
- 我的处理：对照 `upload.py` 里唯一一段可运行的乘法表代码，把执行顺序拆开——
  ```python
  for i in range(1, 10):          # 外层：行，i 从 1 到 9
      for j in range(1, i + 1):   # 内层：列，j 每次都从 1 重新开始，到 i 停
          print(f"{j}*{i}={i * j}", end="\t")  # end="\t" 让它留在同一行
      print()                     # 内层跑完一整遍，才换行，进入下一行
  ```
  关键就三句：**内层必须先跑完，外层才能往前走一步**；内层每次重新从 1 开始，所以第 1 行只有 1 列、第 2 行 2 列……最后是三角形不是方阵；`print()` 不带内容就是换行，删掉它所有结果会挤在一行。已实际运行这段代码验证，输出就是标准的 9 行乘法表（第 1 行 `1*1=1`，第 2 行 `1*2=2  2*2=4`，以此类推）。
