## 今天学了什么

- **字符串**：单引号 / 双引号 / 三引号定义，三引号支持多行原样输出；引号嵌套原则是单引号放双引号里、双引号放单引号里，实在不行用 `\` 转义或三引号；字符串是序列，底层占连续内存，索引从 0 开始，最大索引是 `len - 1`，正索引从左往右、负索引从右往左（-1 是最后一个）。
- **字符串切片**：`序列[开始:结束:步长]`，顾头不顾尾（不含结束位置），开始默认 0、步长默认 1，步长正数从左往右、负数从右往左；`numstr[2:5]`、`numstr[:5]`、`numstr[1:]`、`numstr[:]`、`numstr[::2]`、`numstr[::-1]`（翻转）、`numstr[-2:-5:-1]`、`numstr[0:-1]` 都是这套规则。案例：`avatar.png` 切出 `avatar` 和 `.png`；字符串向右旋转 n 位：`n % len(str)` 防超长，`str[:-n]` + `str[-n:]` 换位拼接。
- **字符串内置方法**：查找 `find()`（找不到返回 -1）vs `index()`（找不到直接报错）；修改 `replace(旧, 新, 次数)`（默认全换）、`split(分隔符)`（切完返回列表）、`join()`（把序列按分隔符拼回字符串）、`title()`（每个单词首字母大写）。**字符串是不可变类型**：修改方法返回的是新字符串，原字符串不变。
- **列表**：一次存多个数据，可混类型，一般存同类型；`[元素1, 元素2, ...]`，索引和切片规则和字符串一致，遍历推荐 for、也可以 while + `len()` + 计数器。
  - 查：`index()`（找不到报错）、`count()`（出现次数）、`in` / `not in`；
  - 增：`append()`（尾部追加一个，列表当整体追加）、`extend()`（把另一个序列逐个追加）、`insert(位置, 元素)`；
  - 删：`del 列表[索引]`、`pop()`（默认删最后一个并返回，`pop(索引)` 删指定）、`remove(元素)`（删第一个匹配项，找不到报错）；
  - 改：`列表[索引] = 新值`、`reverse()`（倒序）、`sort()`（默认升序，`reverse=True` 降序）。
  - 嵌套列表：列表里还可以是列表，如 `students = [['张三','李四'],['王五','赵六'],['田七','钱八']]`，`students[0][1]` 是李四，嵌套 for 可以逐个取出每个名字。
  - 案例：相邻元素最大值，`range(0, len(list1)-1)` 遍历到倒数第二个，避免 `list1[i+1]` 越界（`IndexError: list index out of range`），输入 `[7, 8, 9, 5, 6, 7, 2, 3]` 输出 `[8, 9, 9, 6, 7, 7, 3]`。
- **元组**：存多个数据且**不允许修改**；`(10, 20, 30)`，单个元素必须带逗号 `(10,)` 否则就是那个数据本身的类型；操作方法基本是查询：`元组[索引]`、切片、`index()`、`count()`、`len()`。
  - 案例 1：嵌套元组 `((1,2,3),(2,4,6),(2,3,5))` 提唯一元素，嵌套 for + `not in` 去重，输出 `[1, 2, 3, 4, 5, 6]`；
  - 案例 2：元组 `(1, 2, 3, 4, 5, 6, 7, 8, 9)` 统计奇数个数，`% 2 == 1` 计数。
- **集合（只通过练习案例接触，未系统学）**：集合自带去重，如 `{2, 5, 3, 7, 5, 7}` 实际只有 2、3、5、7；缺失数字案例就是靠这个性质 + `in` 判断做的。
